# Class Compass

A phone web app that points kids to their next classroom with a big arrow, distance in steps, and written directions.

Open it at **https://gone12332.github.io/class-compass/** and tap **Add to Home Screen** to keep it like an app.

- Save each classroom by standing at its door and tapping **Save this spot**.
- Share all classes to another phone with the link under the **⋯** menu.
- GPS indoors can be off by 5 to 20 meters, so add written directions for each room.
